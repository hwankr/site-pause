    기록 기준

    사이트별로 하루 5분을 초과한 날의 전체 시간을 합산해요.

    활성 브라우저 창에서 보고 있는 사이트만 기록해요. 1분 동안 입력이 없거나 시크릿 창을 사용하면 기록이 멈춰요.

    기록을 켠 이후의 도메인과 사용 시간만 이 기기에 저장하며, 최근 30일을 보관해요.

    차단 목록은 현재 저장된 목록을 기준으로, 차단을 꺼 둔 동안의 사용도 포함해요. 페이지·쇼츠·릴스 차단은 해당 사이트 전체 시간을 포함하며, 허용 예외도 제외하지 않아요. 쇼츠·릴스 시청 시간만 따로 구분하지는 않아요.

    모든 사용 기록을 삭제할까요?

    조회 기간과 사이트 필터에 관계없이 저장된 기록이 모두 삭제돼요. 삭제한 기록은 되돌릴 수 없어요.
