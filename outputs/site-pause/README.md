# 잠깐, 집중

버튼 하나로 원하는 사이트를 켜고 끄는 Chrome 확장 프로그램입니다. 타이머는 포함되어 있지 않습니다.

## 설치

1. Chrome 주소창에 `chrome://extensions`를 입력합니다.
2. 오른쪽 위의 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
4. 아래 `site-pause` 폴더를 선택합니다. 폴더 바로 안에 `manifest.json`이 있어야 합니다.

```text
C:\Users\hwan\Documents\Codex\2026-09-18\sd\outputs\site-pause
```

ZIP 파일을 받았다면 먼저 압축을 푼 다음, 그 안의 `site-pause` 폴더를 선택하세요. 설치 후에도 불러온 폴더를 이동하거나 삭제하지 마세요. [Chrome 공식 설치 안내](https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world#load-unpacked)에서도 같은 절차를 확인할 수 있습니다.

이 안내를 여는 것만으로 설치되지는 않습니다. 위 과정으로 Chrome에 직접 불러와 주세요.

## 사용

1. Chrome 도구 모음의 **확장 프로그램** 아이콘에서 **잠깐, 집중**을 고정합니다.
2. 확장 프로그램을 열고 차단 목록을 편집한 뒤 저장합니다. 예: `youtube.com`, `reddit.com`.
3. 공부를 시작할 때 차단을 켭니다. 아이콘의 **ON** 표시로 상태를 확인합니다.
4. 쉬는 시간에는 확장 프로그램에서 차단을 끕니다.

도메인과 그 하위 도메인 전체를 차단합니다. URL을 붙여 넣어도 특정 페이지 경로만 차단하는 것은 아닙니다. 예를 들어 `youtube.com`은 `www.youtube.com`과 `m.youtube.com`에도 적용됩니다.

차단을 켜면 이미 열려 있던 대상 사이트도 차단 화면으로 바뀝니다. 작성 중인 내용은 먼저 저장하세요. 차단을 꺼도 사이트는 자동으로 다시 열리지 않습니다. 차단 화면의 사이트 열기 버튼을 누르거나 직접 다시 방문하세요.

## 설정과 적용 범위

- 확장 프로그램 세부정보에서 **사이트 액세스 → 모든 사이트**를 유지해야 저장한 차단 목록이 작동합니다. 실제 차단 대상은 목록에 등록한 사이트뿐입니다.
- Chrome을 닫았다가 다시 열어도 차단 목록과 켜짐·꺼짐 상태는 유지됩니다.
- 현재 확장 프로그램이 설치된 Chrome 프로필에 적용됩니다. 확장 프로그램을 끄거나 제거한 경우, 다른 프로필, 다른 브라우저에는 적용되지 않습니다.
- 시크릿 창에는 기본적으로 적용되지 않습니다. 필요하면 확장 프로그램 세부정보에서 **시크릿 모드에서 허용**을 직접 켜세요.

차단 목록과 켜짐·꺼짐 상태만 이 브라우저에 저장합니다. 외부 서버, 원격 코드, 분석 도구를 사용하지 않으며 방문 기록을 수집해 저장하지 않습니다. 이미 열린 탭에서 차단 화면으로 전환될 때는 돌아갈 주소를 그 탭의 URL 조각(`#` 뒤)에만 담으며, 별도의 방문 기록으로 저장하지 않습니다.

## 필요한 권한

- `storage`: 차단 목록과 켜짐·꺼짐 상태 저장
- `declarativeNetRequest`: 등록한 사이트로 이동할 때 차단 화면 표시
- HTTP·HTTPS 사이트 접근: 사용자가 등록한 도메인을 차단하고 이미 열린 대상 탭에도 적용
