# 잠깐, 집중

원하는 사이트를 버튼 하나로 차단하는 Chrome 확장 프로그램입니다. 타이머 없이 직접 켜고 끕니다.

## 설치

Chrome 120 이상이 필요하며, 별도 빌드 없이 설치할 수 있습니다.

1. ZIP으로 받았다면 먼저 압축을 풉니다.
2. Chrome 주소창에 `chrome://extensions`를 입력합니다.
3. **개발자 모드**를 켜고 **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
4. **이 README와 `manifest.json`이 있는 폴더**를 선택합니다. 전체 저장소를 받았다면 `outputs/site-pause`입니다.
5. 도구 모음의 **확장 프로그램(퍼즐 아이콘)**에서 **잠깐, 집중**을 고정합니다.

설치 후에도 불러온 폴더를 이동하거나 삭제하지 마세요.

## 사용

1. 확장 프로그램을 열고 **추가**를 누릅니다. 등록한 사이트가 있으면 **편집**으로 표시됩니다.
2. `youtube.com` 같은 주소를 입력하고 **추가 → 저장**을 누릅니다.
3. 팝업에서 **차단 켜기**를 누릅니다. 아이콘에 **ON**이 표시됩니다.
4. 쉬는 시간에는 **차단 끄기**를 누릅니다. 차단됐던 탭의 **사이트 열기**로 돌아갑니다.

사이트를 삭제하려면 **편집 → 주소 옆 × → 저장**을 누르세요. 목록 변경은 **저장**해야 적용됩니다.

## 알아둘 점

- 사이트를 1개 이상 저장해야 차단을 켤 수 있습니다. 최대 200개까지 등록할 수 있습니다.
- 도메인과 하위 도메인 전체를 차단합니다. URL을 붙여 넣어도 특정 페이지만 차단하지는 않습니다.
- 이미 열린 대상 탭도 차단 화면으로 바뀝니다. 작성 중인 내용은 먼저 저장하세요.
- Chrome을 다시 열어도 목록과 차단 상태가 유지됩니다. 시크릿 창은 별도로 허용해야 적용됩니다.
- 차단이 안 되면 저장 여부와 차단 상태, 확장 프로그램 **세부정보 → 사이트 액세스 → 모든 사이트**를 확인하세요.

설정은 현재 브라우저에만 저장하며 외부 서버·분석 도구를 사용하지 않습니다. `storage`는 설정 저장, `declarativeNetRequest`와 사이트 접근 권한은 차단에 사용합니다.
