# 잠깐, 집중

원하는 사이트나 특정 페이지만 차단하고, 허용할 주소를 예외로 둘 수 있는 Chrome 확장 프로그램입니다. 타이머 없이 직접 켜고 끕니다.

## 설치

Chrome 120 이상이 필요하며, 별도 빌드 없이 설치할 수 있습니다.

1. ZIP으로 받았다면 먼저 압축을 풉니다.
2. Chrome 주소창에 `chrome://extensions`를 입력합니다.
3. **개발자 모드**를 켜고 **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
4. **이 README와 `manifest.json`이 있는 폴더**를 선택합니다. 전체 저장소를 받았다면 `outputs/site-pause`입니다.
5. 도구 모음의 **확장 프로그램(퍼즐 아이콘)**에서 **잠깐, 집중**을 고정합니다.

설치 후에도 불러온 폴더를 이동하거나 삭제하지 마세요.

업데이트한 뒤에는 `chrome://extensions`에서 **잠깐, 집중의 새로고침**을 누르세요. 기존 차단 목록은 유지됩니다.

## 사용

1. 확장 프로그램을 열고 **추가**를 누릅니다. 등록한 사이트가 있으면 **편집**으로 표시됩니다.
2. **차단 / 허용**을 고르고, 옆의 적용 범위를 **사이트 전체** 또는 **특정 페이지**로 선택합니다. 주소를 입력하고 **추가 → 저장**을 누릅니다.
3. 팝업에서 **차단 켜기**를 누릅니다. 아이콘에 **ON**이 표시됩니다.
4. 쉬는 시간에는 **차단 끄기**를 누릅니다. 차단됐던 탭의 **사이트 열기**로 돌아갑니다.

사이트를 삭제하려면 **편집 → 주소 옆 × → 저장**을 누르세요. 목록 변경은 **저장**해야 적용됩니다.

## 페이지 차단과 허용 예외

- **차단 + 사이트 전체:** `youtube.com`처럼 입력하면 도메인과 모든 하위 도메인을 차단합니다.
- **차단 + 특정 페이지:** 페이지 URL을 입력하면 등록한 페이지만 차단합니다.
- **허용 + 사이트 전체:** 해당 도메인과 하위 도메인을 차단 예외로 둡니다.
- **허용 + 특정 페이지:** 등록한 페이지만 차단 예외로 둡니다.

YouTube를 차단하면서 노래는 듣고 싶다면 **차단 + 사이트 전체**로 `youtube.com`을 추가한 뒤, **허용 + 특정 페이지**로 듣고 싶은 영상 URL을 추가하고 **저장**하세요. YouTube Music 전체를 허용하려면 **허용 + 사이트 전체**로 `music.youtube.com`을 추가하거나 **YouTube Music 허용** 빠른 추가 버튼을 누르세요.

**허용 규칙이 차단 규칙보다 우선합니다.** 허용 목록은 차단의 예외이며, 나머지 모든 사이트를 차단하는 기능은 아닙니다.

일반 페이지는 `http`/`https`, 호스트, 경로, 쿼리 문자열까지 일치해야 하며 `#` 뒤는 무시합니다. 하위 페이지까지 자동으로 포함하지 않습니다. 여러 페이지 URL은 줄바꿈으로 구분하세요.

YouTube 영상은 영상 ID로 구분하여 `youtu.be` 공유 링크와 YouTube의 일반·모바일·Music 주소를 같은 영상으로 처리합니다. 재생 시각·공유 추적·재생목록 매개변수는 무시합니다. 허용한 영상에서 다른 영상으로 이동하면 다시 차단됩니다. 재생목록 주소만 허용해도 안에 있는 모든 영상이 자동으로 허용되지는 않습니다.

## 알아둘 점

- 사이트 차단 또는 페이지 차단을 1개 이상 저장해야 차단을 켤 수 있습니다. 차단·허용을 합쳐 최대 200개까지 등록할 수 있습니다.
- 기존에 저장한 사이트 차단 목록은 그대로 유지됩니다.
- 이미 열린 대상 탭도 차단 화면으로 바뀝니다. 작성 중인 내용은 먼저 저장하세요.
- Chrome을 다시 열어도 목록과 차단 상태가 유지됩니다. 시크릿 창은 별도로 허용해야 적용됩니다.
- 차단이 안 되면 저장 여부와 차단 상태, 겹치는 허용 규칙, 확장 프로그램 **세부정보 → 사이트 액세스 → 모든 사이트**를 확인하세요.

설정은 현재 브라우저에만 저장하며 외부 서버·분석 도구를 사용하지 않습니다. `storage`는 설정 저장, `declarativeNetRequest`와 사이트 접근 권한은 차단·허용에 사용합니다. `webNavigation`은 YouTube처럼 전체 페이지를 새로 불러오지 않는 화면 이동에도 규칙을 적용하는 데 사용합니다.
