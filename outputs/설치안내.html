Ⅱ 잠깐, 집중

CHROME · QUICK START

설치는 한 번만.
차단은 버튼 하나로.

차단할 사이트를 직접 정하고, 공부할 때 켜세요. 타이머 없이 사용하는 Chrome 확장 프로그램입니다. 아래 순서대로 Chrome에 불러오면 사용할 수 있어요.

  1. 1

    확장 프로그램 화면 열기

    Chrome 주소창에 아래 주소를 입력하고, 오른쪽 위의 개발자 모드를 켜세요.

    chrome://extensions
  2. 2

    준비된 폴더 불러오기

    압축해제된 확장 프로그램을 로드합니다를 누른 뒤, 아래 site-pause 폴더를 선택하세요.

    C:\Users\hwan\Documents\Codex\2026-09-18\sd\outputs\site-pause

    폴더 안에 manifest.json 파일이 있어야 해요. ZIP 파일을 받았다면 먼저 압축을 풀고, 그 안의 site-pause 폴더를 선택하세요. 설치 후에도 이 폴더를 이동하거나 삭제하지 마세요.

    Chrome 공식 설치 안내 ↗

  3. 3

    고정하고, 차단 목록 저장하기

    도구 모음의 확장 프로그램 아이콘에서 잠깐, 집중을 고정하세요. 확장 프로그램을 열고 차단 목록을 편집한 뒤 저장하세요.

    예: youtube.com, reddit.com. 도메인과 하위 도메인 전체를 차단해요. 특정 페이지 경로만 차단하는 방식은 아니에요.

  4. 4

    공부할 때 켜고, 쉬는 시간에 끄기

    확장 프로그램에서 차단을 켜면 아이콘에 ON이 표시돼요. 쉬는 시간에는 같은 화면에서 차단을 끄세요.

    이미 열려 있던 대상 사이트도 차단 화면으로 바뀌니, 작성 중인 내용은 먼저 저장하세요. 차단을 꺼도 사이트가 자동으로 다시 열리지는 않아요. 차단 화면의 사이트 열기 버튼을 누르거나 직접 다시 방문하세요.

알아두면 좋아요

  • 사이트 액세스는 ‘모든 사이트’로
    Chrome의 확장 프로그램 세부정보에서 이 설정을 유지해야 원하는 차단 목록이 작동해요. 실제 차단 대상은 저장한 목록뿐이에요.
  • 브라우저를 다시 열어도 유지
    차단 목록과 켜짐·꺼짐 상태가 저장돼요. 필요할 때 직접 꺼주세요.
  • 현재 Chrome 프로필에서 사용
    확장 프로그램을 끄거나 제거하면 차단되지 않아요. 다른 프로필이나 다른 브라우저에는 적용되지 않아요.
  • 시크릿 창은 별도 허용
    기본적으로 시크릿 창에는 적용되지 않아요. 사용하려면 확장 프로그램 세부정보에서 ‘시크릿 모드에서 허용’을 직접 켜세요.

차단 목록과 켜짐·꺼짐 상태는 이 브라우저에만 저장돼요. 외부 서버나 분석 도구를 사용하지 않으며, 방문 기록을 수집해 저장하지 않아요.

이 파일은 설치 안내입니다. 확장 프로그램은 위 순서에 따라 Chrome에 직접 불러와야 해요.
