잠깐, 집중

Chrome에 설치

ZIP 다운로드
  1. 1

    개발자 모드 켜기

    Chrome 주소창에 입력 → 개발자 모드 켜기

    chrome://extensions
  2. 2

    확장 프로그램 불러오기

    압축해제된 확장 프로그램 로드 → site-pause 폴더 선택

    outputs/site-pause

    ZIP 설치: 압축 해제 → manifest.json이 있는 site-pause 폴더 선택

  3. 3

    차단 시작

    확장 프로그램 메뉴 → 잠깐, 집중 고정

    사이트 목록 저장 → 차단 켜기

  4. 4

    사이트별 사용 시간 확인

    팝업에서 오늘의 총 사용 시간과 많이 사용한 사이트를 확인하세요.

    사용 시간 상세 화면 → 오늘·최근 7일·최근 30일 순위 확인

    설치·업데이트 이후부터 기본으로 기록합니다. 상세 화면에서 기록을 일시정지하거나 삭제할 수 있습니다.

사용 정보
업데이트
같은 폴더에 파일 교체 → chrome://extensions → 잠깐, 집중의 새로고침. 기존 차단 목록과 설정 유지. 이전 방문 기록은 가져오지 않음.
설치 폴더
설치 후 폴더 위치 유지. 폴더 이동·삭제 시 재설치 필요.
사이트 액세스
확장 프로그램 세부정보 → 모든 사이트. 실제 차단은 저장한 목록에만 적용.
차단 범위
사이트 전체 또는 특정 페이지를 선택해 차단. 사이트·페이지 허용 예외가 차단보다 우선 적용.
열려 있는 탭
차단 시 대상 탭도 전환. 작성 중인 내용은 미리 저장. 해제 후 ‘사이트 열기’로 복귀.
설정 저장
차단 목록과 켜짐·꺼짐 상태는 현재 Chrome 프로필에 저장. 브라우저 재실행 후에도 유지.
다른 환경
다른 프로필·브라우저에는 미적용. 확장 프로그램 비활성화·삭제 시 차단 해제.
시크릿 창
차단은 기본 미적용. 확장 프로그램 세부정보 → 시크릿 모드에서 허용. 허용해도 시크릿 창의 사용 시간은 기록하지 않음.
사용 시간
차단 상태와 별개로, 현재 포커스된 Chrome 창에서 보고 있는 HTTP·HTTPS 탭만 기록. 백그라운드 탭·다른 앱 사용 시간 제외. 시스템에서 60초 동안 입력이 없거나 화면이 잠기면 기록 중지.
기록 정확도
약 30초마다 확인하는 근사값. 확인이 오래 지연되거나 컴퓨터가 절전 상태였던 구간은 제외.
보관과 삭제
컴퓨터의 현지 날짜로 오늘을 포함한 최근 30일 보관. 상세 화면에서 기록 일시정지·재시작·삭제 가능. 사용 기록을 삭제해도 차단 목록과 설정 유지.
개인정보
설정과 도메인별 하루 사용 시간은 현재 브라우저에만 저장. 사용 시간 기록에 페이지 경로·제목·전체 방문 내역은 저장하지 않음. 외부 서버·분석 도구 미사용.
추가 권한
alarms: 약 30초 간격으로 사용 시간 확인. idle: 미사용·화면 잠금 상태 확인.
